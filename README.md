# 小奕 / Coaixy

我在做传统术数的程序化实现与 AI Agent 应用，主理 [LookFate](https://github.com/look-fate)。目前正在开发 **FateClaw**，关注排盘算法、知识检索与模型评测。

### 开源项目

- **[liuren-ts-lib](https://github.com/look-fate/liuren-ts-lib)**：基于 tyme4ts 的大六壬排盘库，提供结构化结果与调用接口。
- **[xuanxue-skill](https://github.com/Coaixy/xuanxue-skill)**：面向 Agent 的术数 Skill 集合，整理使用框架与参考资料。
- **[fate_benchmark](https://github.com/look-fate/fate_benchmark)**：基于 BaziQA 的模型评测流程，记录回答、评分与分项统计。
- **[TCM-Ancient-Books](https://github.com/Coaixy/TCM-Ancient-Books)**：中医古籍 OCR 文本的专题整理与检索预处理。
